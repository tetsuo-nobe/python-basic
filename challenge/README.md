## プログラミング課題: FizzBuzz

サンプルコードで学んだ内容を活用して、以下の課題に挑戦してください。`fizzbuzz.py` にコードを記述します。

### 課題内容

1 から 100 までの数値を順番に表示するプログラムを作成してください。ただし、以下のルールに従います。

| 条件 | 表示する内容 |
|------|-------------|
| 3 の倍数のとき | `Fizz` |
| 5 の倍数のとき | `Buzz` |
| 3 と 5 の両方の倍数のとき | `FizzBuzz` |
| 上記以外のとき | その数値をそのまま表示 |

### 期待される出力（先頭部分）

```
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
16
...
```

### ヒント

- basic フォルダにある各サンプルのうち下記を使用します。
- `for.py` で学んだ `for` 文と `range` を使います
- `if.py` で学んだ `if`、`elif`、`else` を使います
- `basic.py` で学んだ `%`（余りを求める演算子）を使います
- 条件の判定順序に注意してください（「3 と 5 の両方の倍数」を最初に判定する必要があります）

### 実行方法

```bash
python fizzbuzz.py
```
